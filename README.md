# 階段の孤島 ― 板橋区（PLATEAU）

停電や浸水のとき、階段しか残らない上の階の高齢者が、どの建物にいそうかを数えるWebツールです。

デモ：https://beyondoor.github.io/kaidan-no-kotou/

## 手元で動かす
1. このリポジトリをダウンロードして、フォルダの中でターミナルを開く
2. 次を実行する
   ```
   python3 -m http.server 8000
   ```
3. ブラウザで http://localhost:8000 を開く（止めるときは Control＋C）

index.html をダブルクリックで開くと、データを読めずに動きません。
3D表示の部品（deck.gl）と文字（Noto Sans JP）はインターネットから読み込みます。

## 操作
- 場面（平時／停電／洪水＋停電）と、2本のスライダー（何階から上を数えるか・エレベーターのない確率）を動かすと、全棟をブラウザの中で数え直します
- 建物をクリックすると、その建物の断面と推定人数が出ます
- 「訪問リスト（A4）」：選んだ町丁目の建物を推定人数の多い順に並べます（CSVでコピーできます）
- 「自動デモ」：字幕つきで約2分、自動で進みます。「動画を書き出す」で同じ流れを動画（webm）にできます
- キー h：パネルを隠して地図だけにする／キー b：高島平２丁目の例の1棟の断面を出す

## ファイル
- index.html：画面と計算（計算はすべてブラウザの中）
- data.json.gz：板橋区の共同住宅21,476棟と周りの建物の形・属性、町丁目の人口（gzipで圧縮）
- prep.py：data.json を作るスクリプト
  `python3 prep.py itabashi_plateau_buildings.json itabashi_age_by_chome.csv data.json`
- analysis/verify.py：画面と同じ式で推定人数を計算し直し、ブラウザの数字と合うか確かめるスクリプト。町丁目の順位の安定度も、画面より多い回数で調べられます（標準ライブラリだけで動きます）
  `python3 analysis/verify.py --trials 1000`

## データと出典
- 国土交通省 Project PLATEAU 板橋区 建築物モデル（2025年度、LOD1、3D Tiles）CC BY 4.0 を加工
- 板橋区「令和7年版 板橋区の統計」（住民基本台帳 令和8年1月1日現在、国勢調査 令和2年）
- 人数はすべて推定です。推定の方法と仮定は、画面のパネルの下に書いてあります。
